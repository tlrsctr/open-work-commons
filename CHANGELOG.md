# Changelog

All notable changes to Open Work Commons will be recorded here. Versions follow Semantic Versioning only after a distribution and compatibility policy is published; development-preview identifiers describe source snapshots, not supported packages.

## 0.1.0-dev.0 - 2026-08-10

- Added the first complete operator-inspectable handoff flow from caller-supplied Entire checkpoint detail and exact local Git state.
- Added Ed25519 device identity, deterministic signed archives, explicit signer trust, offline verification and optional external repository comparison.
- Added transcript-minimized, cited and byte-bounded resume bundles for Codex and Claude.
- Added a private fail-closed local store, an independent conformance implementation and a 55-vector malicious archive corpus.
- Added a frozen cross-agent benchmark, synthetic quickstart, supported CI matrix, public threat model, RFCs and release-readiness audit.
- Published the dated prior-art scan that narrows OWC to a work-checkpoint trust and interoperability layer rather than a generic session handoff tool.
